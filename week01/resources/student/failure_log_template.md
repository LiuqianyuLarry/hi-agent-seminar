# Week 1 failure log

Write 300-500 words in your own voice. Replace every placeholder. Do not report
deliberate mutations as mistakes naturally made by the model.

## Run context

Date, command, case, DeepSeek model, request ID, and relevant saved record.

## What failed

Quote the exact input and the relevant output or validation error. State whether
the error happened naturally or was deliberately injected into the output.

## Why it mattered

Explain whether this was a format/type problem, an unsupported claim, a missing
source, contradictory evidence, or a network/configuration issue.

## What I changed

Describe one code, prompt or checking change. Explain why it addresses the failure.
Do not say that a prompt edit retrained the model.

## Evidence after the change

Give the second run command and result. State which check now passes, which
uncertainties remain, and where human review is still required.

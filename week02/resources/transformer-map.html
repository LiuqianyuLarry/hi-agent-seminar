See how the original 2017 Transformer connects input and output sequences.

A representation is a vector at each position; N x repeats blocks.

Code: MiniGPT

MiniGPT: Our decoder-only model has no encoder and no cross-attention. Its blocks use Pre-LN; the original figure shows Add & Norm after sublayers.

Left encoder stack and its Multi-Head Attention

Read the given source sequence and produce representations for the decoder to consult.

Encoder self-attention gets Q,K,V from the source sequence; decoder cross-attention uses its output for K,V.

Code: No corresponding MiniGPT encoder

MiniGPT: The original encoder can attend across the supplied source sequence. This causal decoder-only MiniGPT does not implement that encoder or its unmasked source-attention branch.

Input Embedding / Output Embedding

Turn discrete character IDs into trainable vectors.

E: [V,d]; lookup -> [B,T,d].

Code: MiniGPT.token_embedding; MiniGPT.forward

MiniGPT: The local input uses 96 character symbols, not a commercial tokenizer. IDs come from data.py.

Positional Encoding and plus sign

Provide the position of each token.

x_t=E[token_t]+P[t].

Code: MiniGPT.position_embedding; MiniGPT.forward

MiniGPT: The original paper uses sinusoidal positions; this model learns a position table.

Outputs (shifted right)

Supply known characters while the target is the following character.

x=tokens[s:s+T]; y=tokens[s+1:s+T+1].

Code: data.make_batches

MiniGPT: The supplied character windows express next-token shifting without adding a special translation start token.

Masked Multi-Head Attention

Gather only permitted past/current context.

A=softmax(QK^T/sqrt(H)+M); O=AV.

Code: AttentionHead.forward

MiniGPT: Our causal switch is used only for the controlled failure demo; normal attention stays causal.

Multi-Head Attention inside the masked decoder sublayer

Learn several mixtures of the same input features.

concat(head_1,...,head_h) W_O; h*H=d.

Code: MultiHeadAttention.forward

MiniGPT: A Python list comprehension is explicit teaching code; it does not imply automatic simultaneous kernel execution.

Middle decoder Multi-Head Attention with arrows from encoder

Read encoder information using decoder queries in translation.

Q from decoder; K,V from encoder.

Code: No corresponding MiniGPT module

MiniGPT: Omitted in this decoder-only model. Do not call the middle decoder box another copy of its masked self-attention.

Add & Norm and residual arrows

Add a computed change to the representation and normalize features.

a=x+Attention(LN1(x)); z=a+FFN(LN2(a)).

Code: TransformerBlock.forward; norm1; norm2

MiniGPT: Pre-LN is an intentional difference from the original Post-LN diagram. These operations help training; they do not guarantee gradients can never vanish or explode.

Feed Forward

Apply the same nonlinear feature transform separately at each position.

project(GELU(expand(x))); d -> 4d -> d.

Code: FeedForward.forward

MiniGPT: This MiniGPT uses GELU. The 2017 paper uses ReLU. FFN itself does not mix token positions.

N x bracket

Repeat blocks to build deeper representations.

[B,T,d] -> block -> [B,T,d], repeated L times.

Code: MiniGPT.blocks; nn.Sequential

MiniGPT: L=2 here. Heads are registered with ModuleList; blocks with Sequential so the optimizer can find their parameters.

Linear above decoder

Score every possible next character.

[B,T,d] -> [B,T,V].

Code: MiniGPT.final_norm; MiniGPT.lm_head

MiniGPT: forward returns raw logits; the added final norm is part of this MiniGPT implementation.

Softmax / Output Probabilities

Convert scores to probabilities when sampling the next character.

p_i=exp(z_i)/sum_j exp(z_j); cross-entropy=-ln p_target.

Code: MiniGPT.generate; train.train_step

MiniGPT: Generation applies Softmax for sampling. F.cross_entropy handles logits directly in training; do not apply Softmax twice.

Matrix computations throughout the figure

Relate repeated matrix work to measured CPU/CUDA performance.

tokens/s=steps*B*T/time; one score matrix has B*h*T*T elements.

Code: train.run; train.sync; benchmark.main

MiniGPT: The device comparison measures a fixed training interval. It excludes I/O, transfer, evaluation, generation and plotting.

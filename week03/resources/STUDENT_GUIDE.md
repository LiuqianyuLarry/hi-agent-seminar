# Week 3 activity map

Choose Review with code or Start exercises. Both last 100 minutes and include
the same MCP lesson. Optional foundations offer Continue / Brief explanation /
Simple example. Ask for a hint whenever you need one.

| Task | Purpose | Evidence |
|---|---|---|
| 1 | Separate model reasoning from data access | Explain the roles; check environment |
| 2 | Summarise supplied temperatures | Your function, tests and output explanation |
| 3 | Read the CONV-3 register | Your function, source/version and error checks |
| 4 | Read a precise time window | Your query, read-only tests and record list |
| 5 | Follow a DeepSeek call | Match the proposed call to the returned result |
| 6 | Test real tool selection | Three real DeepSeek traces and your assessment |
| 7 | Locate failures and improve descriptions | Injected cases and before/after evidence |
| 8 | Understand MCP and expose a tool | Full introduction, wrapper, real client/server test |
| 9 | Connect MCP to the assistant | Compare the MCP trace with the local trace |
| 10 | Explain the complete chain | Your short reflection and saved progress |

Each checkpoint adds 10% after the required understanding check. Percent means
completed learning milestones, not minutes elapsed. Pause and resume in the
same workspace. If online access fails, keep your completed local work; the
online requirement stays pending until it is actually tested.

Core live tasks have at most 12 requests in total before any approved retries.
You do not need a GPU. Do not mistake synthetic teaching records for real plant
history. Optional extensions cover seven-case evaluation, more boundary tests,
and resources/context. Autonomous multi-step loops belong to a later week.

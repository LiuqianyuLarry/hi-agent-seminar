# Original lecture pages for guided review

These nine PNG files are read-only PowerPoint exports from the instructor's
Week 3 lecture deck, not newly drawn slides. SOURCE.json records the deck hash,
page numbers and image hashes. Load only the page for the current teaching step.

The review path explains the original page before opening implementation code:
locate the important parts of the diagram, state the concept in plain English,
trace a CONV-3 example, then show how the current code implements it.

The source deck contains some Responses-style API fields. Those are discussed as
lecture illustrations. The packaged code uses DeepSeek Chat Completions, so the
mentor must explain the explicit field mapping instead of presenting the older
slide snippet as a runnable DeepSeek request. The original images stay unchanged.

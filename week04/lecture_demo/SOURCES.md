# Course sources

Adapted from the instructor-supplied Week 4 teaching pack and student pack. The original Week 4 slides explain the same temperature case.

Changes for this plugin: English teaching text and outputs; CONV-3 identifiers; short loop-step exercise; DeepSeek Chat Completions; generated local SQLite; bounded problem demonstrations. The files are not byte-identical to the original pack. See WEEK03_REUSE.json and data/manifest.json.

The observations use synthetic classroom data. No historical validation result is claimed as a new test of these adapted files.

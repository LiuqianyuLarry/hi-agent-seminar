# CONV-3 temperature review manual

Synthetic teaching material. Not a real manufacturer document.

## Reference temperature

For CONV-3 model MX-A, the classroom temperature reference is 85 C. This is a teaching reference, not a manufacturer safety limit. Use the reference version that applies at the requested time.

## 4.2 Temperature review and evidence

For CONV-3 model MX-A, if more than three readings in a 25-minute window strictly exceed 85 C, retain the raw readings, timestamps, machine identifier, reference and manual version. Obtain the sensor calibration record and the operating-load log for the same window before making any root-cause claim. Temperature readings alone cannot confirm bearing failure or any other cause.

## Interpretation limits

Five samples are not a continuous temperature record. The fraction of samples above a reference is not the fraction of time above it and is not a fault probability. Report missing measurements explicitly rather than replacing them with zero.
